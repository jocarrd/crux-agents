crux setup — gets this machine ready, step by step, asking what it cannot work out.

  crux setup [--owner <owner>] [--projects-dir <dir>]

Seven steps, each of which looks first at what is already done and skips it:
git and GitHub (it offers 'gh auth login' if gh has no session), where new
repos go (your account or one of your organisations, cloned the way the
account clones), the projects folder, crux itself, your profile (brought from
the remote, or created), your projects (the account's, picking which to bring; if it
has none, the first one is created with you), and what the machine still
lacks for the skills.

Run it again at any time. Without a terminal —an agent, a script, CI— it asks
nothing: it takes the defaults, says what is missing and how to give it as an
option.
